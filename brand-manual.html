Reglas del Sistema

Dark-only. Kronos no tiene modo claro. html siempre recibe fondo --k-bg #08080a.

Monocromático. Un solo color de acento: lima neon #c8ff2d. No se mezclan rojo, azul, cyan ni violeta como acento de marca.

Intensidad por opacidad. Para comunicar niveles (bajo/medio/alto) dentro de la misma categoría, variar la opacidad del acento (rgba(200,255,45,0.X)), no cambiar de color.

Semánticos solo para semántica. --k-warning y --k-danger solo para advertencias reales y errores — no como decoración.

Hex prohibidos. #19f08b (verde teal), #3aa3ff (cyan), #1a3457/#0d1b2e/#07101e (navy), #6c3de0 (violeta). Son residuos de V1/V2.

Tokens canónicos. Siempre usar var(--k-*). El compat layer (--red, --blue, --grad…) existe como red de seguridad, no como API pública.

Nota de Accesibilidad

--k-t3 (#54545c) falla WCAG AA para texto normal sobre --k-bg (#08080a).
Ratio aproximado: ~2.4:1 (mínimo requerido: 4.5:1 para texto normal, 3:1 para texto grande).
Uso permitido: etiquetas ornamentales, timestamps, metadatos secundarios, decoración.
Nunca usar para contenido informativo crítico. Para texto legible usar --k-t2 (#8a8a94, ~4.8:1) o --k-t1.
